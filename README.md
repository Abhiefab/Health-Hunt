# Health Hunt

## Project Overview

Health Hunt is a 3D first-person perspective exploration game developed using Unity and C#. The game challenges players to explore a house, search through multiple rooms, and collect all the hidden health boxes within a limited amount of time.

Players must navigate through the house, open locked or closed doors using keyboard interaction, and carefully explore every room to find the required health boxes. Time management and exploration are essential to completing the mission successfully.

## Game Objective

The main objective is to find and collect all the health boxes hidden throughout the house before the countdown timer reaches zero.

Players must explore different rooms, interact with doors, and search every accessible area to complete the mission.

## Gameplay Features

- First-Person Exploration: Explore the house through a first-person perspective.
- Interactive Doors: Open doors using keyboard interaction to access different rooms.
- Health Box Collection: Search for and collect hidden health boxes throughout the house.
- Time-Based Challenge: Complete the mission within the available time.
- Multiple Room Exploration: Navigate through different rooms and discover hidden locations.
- Objective Tracking: Find all health boxes to successfully complete the mission.
- Win and Lose Conditions: Complete the objective before time expires or fail the mission.

## Game Controls

| Key | Action |
|---|---|
| W | Move Forward |
| S | Move Backward |
| A | Move Left |
| D | Move Right |
| Mouse | Look Around |
| O | Open Doors |

## Game Objective and Conditions

### Winning Condition

Successfully locate and collect every health box throughout the house before the countdown timer expires.

### Losing Condition

If the countdown timer reaches zero before all health boxes are collected, the player fails the mission.

## Technologies Used

- Unity
- C#
- Blender for 3D Assets and Environment Modeling

## How to Run the Project

1. Clone or download this repository.
2. Install Unity Hub and a compatible Unity Editor version.
3. Open Unity Hub.
4. Select Add Project from Disk.
5. Choose the downloaded Health Hunt project folder.
6. Open the project in Unity.
7. Open the main game scene and press Play to start.

## Project Structure

- Assets: Contains game assets, scripts, scenes, materials, and other resources.
- Packages: Contains Unity package dependencies.
- ProjectSettings: Contains project configuration and settings.
- Health-Hunt.sln: Visual Studio solution file for C# development.
